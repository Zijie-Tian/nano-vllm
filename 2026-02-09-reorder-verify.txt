  实验结果总结

  Density Profiling

  - 32 个 Q head 的 density 分布呈双峰：7 个极稀疏 head（density ≈ 0.008，只需 1
   个 block）和 25 个不同程度 dense 的 head
  - Density 范围：0.008 ~ 0.854，均值 0.383，标准差 0.286

  Regrouping 结果

  贪心算法将 32 个 head 分为：
  ┌───────┬────────┬─────────┬────────────────────────┐
  │ Group │  类型  │ Head 数 │     Union Coverage     │
  ├───────┼────────┼─────────┼────────────────────────┤
  │ G0    │ Dense  │ 25      │ 99.2% (122/123 blocks) │
  ├───────┼────────┼─────────┼────────────────────────┤
  │ G1    │ Sparse │ 3       │ 0.8% (1/123)           │
  ├───────┼────────┼─────────┼────────────────────────┤
  │ G2    │ Sparse │ 2       │ 0.8% (1/123)           │
  ├───────┼────────┼─────────┼────────────────────────┤
  │ G3    │ Sparse │ 2       │ 0.8% (1/123)           │
  └───────┴────────┴─────────┴────────────────────────┘
  KV Load Reduction

  - 原始分组总 KV block 加载量：425
  - Regrouped 总加载量：125
  - 减少 70.6%

  等价性验证

  - Attention 计算有效性（行和 = 1.0）：通过，误差 < 4.17e-07
  - 关键发现：Regrouping 改变了 Q-KV 配对关系后，输出不再数值等价
    - 同一 KV group 的 head（如 H0, H7）输出不变
    - 跨 KV group 的 head（如 H16: KV2→KV0）输出差异显著，cos_sim 低至 -0.017

  核心结论

  1. Regrouping 策略本身可行：确实能将 sparse heads 隔离，大幅减少 sparse groups
   的 KV 加载
  2. 但数学等价性不成立：方案文档中 Section 3.2 的分析是正确的 — GQA 训练时各 KV

  关键发现

  1. 64k 下 sparse head 更少 — 16k 有 7 个极稀疏 head (H1,2,6,11,14,25,27)，64k
  只剩 3 个 (H1,2,6)。序列越长，更多 head 变得 dense，这符合直觉。

  2. 分组极度不平衡加剧 — 29:1:1:1 的分配比 16k 的 25:3:2:2 更极端，说明在 64k
  下大多数 head 都需要覆盖大量 K blocks。

  3. Dense head 一致性 — H1, H2, H6 在 16k 和 64k 下都是最稀疏的 head，这些 head
   的稀疏性是结构性的（方案文档中假设 1 成立）。同时 H21, H28, H23, H18
  在两个长度下都是最 dense 的 head。

  4. 等价性问题不变 — 跨 KV group 配对后 cos_sim 同样很低（H16: -0.025, H24:
  0.011），确认 regrouping 改变 Q-KV 配对会显著影响输出。

  5. Block coverage 图 — 上图清晰展示了原始分组下每个 KV group 的 union 都在
  60%-100%，而 regrouped 后 sparse groups 几乎只需 0.2% 的 blocks。左侧 load
  analysis 柱状图显示 regrouped 的 G1-G3 union coverage 接近零。

  核心问题

  Greedy 算法的优化目标是最小化 sparse groups 的 max union，但由于 GLM-4-9B 只有
   4 个 KV head、极少 sparse head，算法把几乎所有 head 塞进 dense group —
  这在实际推理中意味着 dense group 承载 29 个 Q head
  的计算，并不能改善整体推理延迟，因为瓶颈仍在 dense group 的 100% KV 加载上。
