# COMPASS Documentation Management

This skill keeps Codex aligned with `.codex/rules/doc-management.md`.

## Required first step
Read `.codex/rules/doc-management.md`.

## Enforce
- Keep `CLAUDE.md` focused on operational requirements.
- Put detailed technical content in `docs/`.
- When adding a new technical doc, update the documentation index in `CLAUDE.md` and `GEMINI.md`.
- For analysis-style docs, include both theoretical reasoning and empirical validation when the rule requires it.
